# Джарвисджон для Android

Рабочая ветка: `Jarvisjon-ru`. Основа: [ClawDroid](https://github.com/KarakuriAgent/clawdroid), лицензия MIT сохранена.

Целевой телефон: Samsung Galaxy S25, Android 16, One UI 8.5. Работа на устройстве пока не проверена.

## Текущее состояние

1. Интерфейс и каталоги сообщений переводятся на русский.
2. Озвучка использует установленный локальный русский голос Android. Голос не включён в APK; нужен русский пакет TTS на телефоне. Сходство с голосом Джарвиса не подтверждено.
3. Понимание команд работает через API модели. Ключ вводится в настройках приложения и не нужен для сборки.
4. GitHub Actions собирает тестовый APK со встроенным Go модулем для ARM64. Это тестовая подпись, не выпуск для распространения.
5. Согласованные подтверждения критичных действий, защищённое хранение ключей, фильтрация экрана и защита от повторов ещё требуют реализации и проверки. Не используйте текущую сборку для автоматической отправки, удаления, платежей или работы с секретами.

## Согласованное поведение первой версии

Открытие приложений, поиск, прокрутка, подготовка текста и обычное напоминание по явной команде выполняются автоматически. Отправка сообщений и файлов, звонки, публикации, удаление и перезапись, покупки, предоставление доступа и важные настройки требуют подтверждения одного конкретного действия. Изменение деталей аннулирует подтверждение. Неизвестный результат отправки не допускает автоматического повтора. Банковские операции и ввод секретов выполняются вручную.

## Сборка

Во вкладке Actions выберите «Сборка Джарвисджон», ветку `Jarvisjon-ru`. После успешных проверок APK находится в артефакте `Jarvisjon-ru-S25-test`. Пакет тестовой версии: `io.jarvisjon.android.debug`.
